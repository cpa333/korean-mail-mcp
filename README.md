# korean-mail-mcp

Claude Code에서 **네이버·다음 메일을 읽고, 답장·새 메일 초안을 임시보관함에 저장**하는 MCP 서버입니다.

- 메일 검색, 메일 읽기, 첨부 파일 내려받기, 초안 저장(새 메일·답장·전체 답장)을 할 수 있습니다.
- **메일을 발송하지 않습니다.** 초안은 웹메일 임시보관함에서 확인하신 뒤 직접 발송해 주세요.
- 메일 주소와 앱 비밀번호는 사용자 PC에만 저장됩니다. 외부 서버를 거치지 않고 메일 서버에 바로 접속합니다.
- 같은 서비스의 계정을 여러 개 등록할 수 있습니다.

## 준비물

- [Claude Code](https://claude.com/claude-code) (CLI 또는 데스크톱 앱의 Claude Code 모드)
- [Node.js](https://nodejs.org) 22 이상 (LTS 버전 권장)
- 연결할 메일 계정의 **IMAP 사용 설정**과 **앱 비밀번호**

## 설치

터미널(Windows는 PowerShell)에서 아래 명령을 실행해 주세요.

```
npx -y @cpal1828/korean-mail-mcp setup
```

1. **계정 추가**를 선택하고 메일 서비스를 고릅니다.
2. 화면의 준비 단계에 따라 IMAP을 켜고 앱 비밀번호를 만듭니다.
3. 메일 주소와 앱 비밀번호를 입력하면 그 자리에서 접속을 확인합니다.
4. **완료 (저장)**를 선택하면 Claude Code에 등록됩니다.
5. Claude Code를 다시 시작합니다.

계정을 추가하거나, 비밀번호를 바꾸거나, 삭제할 때도 같은 명령을 실행해 주세요. 기존 계정은 그대로 유지됩니다.

### 버전 고정과 업데이트

setup은 지금 실행한 버전으로 고정해 Claude Code에 등록합니다. 새 버전이 배포되어도 자동으로 바뀌지 않으므로, 혹시 문제가 있는 버전이 배포되더라도 setup을 다시 실행하기 전까지는 영향을 받지 않습니다.

업데이트하려면 아래 명령으로 최신판 setup을 실행하고 **완료 (저장)**를 선택해 주세요. 화면에 "실행 명령이 바뀝니다"가 나오면 새 버전으로 다시 등록됩니다. 등록된 계정은 그대로 유지되고, 앱 비밀번호를 다시 입력할 필요가 없습니다. (0.1.2 이하에서 실행한 setup으로는 계정을 바꾸지 않으면 업데이트되지 않았습니다.)

```
npx -y @cpal1828/korean-mail-mcp@latest setup
```

### 패키지 이름 확인

- 패키지 이름은 반드시 `@cpal1828/korean-mail-mcp`입니다(앞의 `@cpal1828/`까지 포함). 앞부분이 없는 `korean-mail-mcp`는 이 패키지가 아닙니다.
- GitHub 계정 `cpa333`과 npm 계정 `cpal1828`은 같은 배포자입니다. 소스 코드: https://github.com/cpa333/korean-mail-mcp

### 앱 비밀번호 만들기

**네이버**
1. IMAP 켜기: 네이버 메일 → 환경설정 → POP3/IMAP 설정 → IMAP/SMTP 사용 → '사용함'
2. 앱 비밀번호 만들기(2단계 인증이 꺼져 있으면 먼저 켭니다): 네이버 내정보 → 보안설정 → 2단계 인증 '관리' → 애플리케이션 비밀번호 관리 → '직접 입력'에 10자 이내 이름(예: mailmcp) → 생성

자세한 안내: https://help.naver.com/service/5640/contents/8584?osType=COMMONOS

**다음**
1. IMAP 켜기: 다음 메일 → 환경설정 → IMAP/POP3 → IMAP/SMTP 사용 → '사용함' → 저장
2. 앱 비밀번호 만들기: 다음 회원 → 마이페이지 → 계정 보안 → 앱 비밀번호 → 휴대폰 2차 인증 → 이름 입력(예: mailmcp) → 생성

2025년 12월 1일부터 다음 메일 앱 비밀번호는 다음 회원 마이페이지에서만 만들 수 있습니다. 카카오계정에서 만든 비밀번호는 사용할 수 없습니다.

자세한 안내: https://cs.daum.net/faq/43/9234.html?faqId=31143

앱 비밀번호는 한 번만 표시되므로 바로 복사해 주세요.

## 사용 예

Claude Code에서 평소처럼 요청하시면 됩니다.

- "네이버 메일에서 이번 주에 한국공인회계사회가 보낸 메일 찾아 줘"
- "그 메일 첨부 파일 받아서 내용 정리해 줘"
- "정리한 내용으로 전체 답장 초안 만들어 줘"

계정이 여러 개이고 요청에서 어느 계정인지 분명하지 않으면 Claude가 먼저 여쭙니다.

## 도구

| 도구 | 하는 일 |
|---|---|
| `list_accounts` | 등록된 계정 목록 |
| `list_folders` | 메일함 목록 |
| `search_emails` | 보낸 사람(이름·주소), 제목, 기간, 안 읽음으로 검색(기본 최근 30일) |
| `read_email` | 메일 읽기. 읽음 표시를 남기지 않습니다 |
| `download_attachment` | 첨부 파일을 다운로드 폴더(또는 지정한 폴더)에 저장 |
| `create_draft` | 새 메일·답장 초안을 임시보관함에 저장. 답장은 전체 답장이 기본입니다 |

## 첨부 파일 저장 규칙

메일에 속은 AI가 PC를 해치지 못하도록 저장 위치와 파일 종류를 제한합니다.

- 기본으로 다운로드 폴더에 저장합니다. 대화에서 다른 폴더를 말씀하시면 그 폴더에 저장하고, 폴더가 없으면 만듭니다.
- **실행 파일은 저장하지 않습니다**(`.exe`, `.bat`, `.cmd`, `.ps1`, `.js`, `.vbs`, `.msi`, `.lnk`, `.jar`, `.sh`, 디스크 이미지 `.iso`·`.img`·`.vhd` 등). 꼭 필요하면 웹메일에서 직접 받아 주세요. 압축 파일은 저장합니다.
- 이름이 점으로 시작하는 첨부(예: `.gitconfig`)는 프로그램 설정 파일로 동작하지 않도록 앞에 `_`를 붙여 저장합니다(`_.gitconfig`).
- 다음 위치에는 저장하지 않습니다. 초안에 첨부할 파일도 같은 규칙을 따릅니다.
  - 네트워크 경로(`\\서버\공유` 등). 직접 연결해 둔 네트워크 드라이브(`Z:` 등)는 사용할 수 있습니다
  - 시작프로그램 폴더처럼 로그인할 때 자동으로 실행되는 폴더
  - Windows·Program Files 같은 시스템·프로그램 폴더(macOS·Linux는 `/etc`, `/usr` 등)
  - 앱 데이터 폴더(Windows `AppData` 전체, macOS `~/Library`). 임시 폴더도 여기에 들어 있어, 초안에 첨부할 파일은 다운로드나 문서 폴더에 두어야 합니다
  - 이름이 점으로 시작하는 폴더와 파일(`.ssh`, `.claude`, `.aws` 등)
- **"인터넷에서 받은 파일" 표시:** Windows에서는 브라우저로 받은 파일과 같은 표시를 붙여 저장합니다. 그래서 열 때 경고가 나올 수 있고, Office 문서는 **제한된 보기**로 열리며 매크로가 차단됩니다. 믿을 수 있는 파일이면 화면 위의 **편집 사용**을 눌러 주세요. USB(FAT32)나 네트워크 드라이브처럼 표시를 붙일 수 없는 곳에 저장하면 결과에 경고가 함께 나옵니다.
- 메일에 들어 있는 파일을 그대로 저장합니다. 한글이 든 CSV가 엑셀에서 깨져 보이면 원본 파일의 문자 인코딩 때문이며, 엑셀의 데이터 → 텍스트/CSV 가져오기에서 UTF-8을 선택하면 열 수 있습니다.

## 크기 제한

- 50MB를 넘는 메일은 읽기, 첨부 파일 받기, 답장 초안 만들기를 하지 않습니다. 웹메일에서 직접 확인해 주세요.
- 초안에 첨부하는 파일은 합계 20MB까지입니다.

## 알아 두실 점

- **비밀번호 저장 위치:** 메일 주소와 앱 비밀번호는 Claude Code 사용자 설정 파일(홈 폴더의 `.claude.json`)에 암호화되지 않은 상태로 저장됩니다. PC를 다른 사람과 함께 쓰신다면 주의해 주세요.
- **비밀번호가 화면에 보이는 명령:** `claude mcp get korean-mail`은 앱 비밀번호를 화면에 그대로 보여 줍니다. 화면을 공유하는 중에는 실행하지 말아 주세요.
- **등록하는 동안의 노출:** setup이 Claude Code에 등록하는 몇 초 동안, 같은 PC의 같은 사용자나 관리자가 볼 수 있는 프로세스 목록이나 프로세스 감사 로그에 앱 비밀번호가 보일 수 있습니다. Claude Code가 비밀번호를 명령 인자로만 받기 때문입니다.
- **메일 내용 속 지시:** 메일 본문에 적힌 지시는 따르지 않도록 Claude에게 안내하고 있습니다. 다만 모르는 사람이 보낸 메일을 다룰 때는 Claude가 실행하려는 작업을 확인해 주세요.
- **예약 작업:** 정해진 시간에 메일을 확인하려면 데스크톱 앱의 예약 작업이나 `/loop`를 사용해 주세요. 클라우드 예약 작업에서는 이 MCP를 사용할 수 없습니다.

## 제거

- Claude Code에게 "korean-mail MCP 지워 줘"라고 요청하시거나 `claude mcp remove korean-mail -s user`를 실행해 주세요.
- 한 계정만 지우려면 setup에서 **계정 삭제**를 선택해 주세요.
- **앱 비밀번호를 반드시 폐기해 주세요.** 등록을 지워도 Claude Code가 자동으로 만든 설정 파일 백업에 앱 비밀번호가 남아 있을 수 있습니다. 네이버·다음에서 앱 비밀번호를 발급한 메뉴에서 폐기할 수 있습니다.
- 내려받은 첨부 파일은 지워지지 않습니다. 받은 순간부터 사용자의 파일이므로 필요 없으면 직접 지워 주세요.

## 수동 설치

setup을 쓸 수 없는 경우 아래처럼 직접 등록할 수 있습니다. 같은 서비스의 두 번째 계정부터는 `NAVER_2_EMAIL`, `NAVER_2_APP_PASSWORD`처럼 번호를 붙입니다.

```
# macOS·Linux
claude mcp add --scope user korean-mail -e NAVER_EMAIL=me@naver.com -e NAVER_APP_PASSWORD=앱비밀번호 -- npx -y @cpal1828/korean-mail-mcp@0.1.3

# Windows
claude mcp add --scope user korean-mail -e NAVER_EMAIL=me@naver.com -e NAVER_APP_PASSWORD=앱비밀번호 -- cmd /c npx -y @cpal1828/korean-mail-mcp@0.1.3
```

- **직접 입력하면 앱 비밀번호가 터미널 명령 기록에 남습니다.** 가능하면 setup을 사용해 주세요.
- `0.1.2` 자리에는 npm 패키지 페이지에 있는 최신 버전을 넣어 주세요. setup과 같이 버전을 고정해 두면 새 버전이 배포되어도 자동으로 바뀌지 않습니다.
- `--scope user`는 모든 프로젝트에서 쓸 수 있도록 사용자 설정에 등록합니다. 빼면 현재 폴더에서만 보입니다.
- Windows는 `npx`를 바로 실행하지 못해 `cmd /c`로 감쌉니다.
